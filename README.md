# Sentiment Analysis of Smartphone Reviews

A Python-based Data Science project that analyzes customer reviews of
smartphones and classifies them as Positive, Negative, or Neutral.

## Project Overview

This project analyzes a dataset of 500 smartphone reviews containing
brand, rating, review text, price and sentiment information.

## Technologies Used

- Python
- Pandas
- NumPy
- SciPy
- Matplotlib
- NLTK
- Scikit-learn
- SQLite

## Features

- Excel dataset handling
- Data cleaning and preprocessing
- Missing value handling
- Duplicate removal
- Sentiment analysis
- Brand-wise analysis
- Statistical analysis
- Probability and sampling
- Chi-Square hypothesis testing
- NLP preprocessing
- TF-IDF vectorization
- Logistic Regression
- Model evaluation
- SQLite CRUD operations
- Data visualization

## Machine Learning

TF-IDF is used to convert review text into numerical features.
A Logistic Regression model is then used for sentiment classification.

The project report states an accuracy of 88% on the test dataset.

## Dataset

The dataset contains 500 smartphone reviews from brands including:

- Apple
- Samsung
- OnePlus
- Redmi
- Oppo
- Nokia
- realme
- Google Pixel
- Vivo
- Motorola
